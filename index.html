Selected work

WiQAS

Filipino cultural question answering, grounded in retrieved evidence

Students can find Filipino heritage content online but rarely verify it. WiQAS answers only from retrieved sources, so every answer can be checked.

  • Cultural LLM Judge. A custom judge prompt and rubric alongside RAGAS, built for a low-resource language rather than borrowed from English benchmarks.
  • Failure analysis. Eight pipeline configurations produced a three-tier taxonomy: retrieval, generation, and cultural failure. Cultural failures are often silent.
  • Result. Outstanding Thesis Award, and the basis of a PRICAI 2026 paper.

BM25 + BGE-M3 hybrid retrieval, Gemma and SEA-LION via Ollama, RAGAS

Lex

When does retrieval earn its cost over prompting alone?

A RAG assistant for the Philippine Revised Penal Code, built with a course partner. We ran an ablation on 20 legal queries to separate what prompt engineering contributes from what retrieval contributes.

Failure modes found, each with a proposed fix

  • Retrieval miss
  • Hallucination and precision errors
  • Formatting and similarity underperformance
  • Statutory metadata confusion

Orion

A local, private RAG assistant

Chat over a personal knowledge base with no cloud dependency. It uses hybrid retrieval with cross-encoder reranking, generation through Ollama, and voice output. It ships as a Tauri desktop app with a bundled Python runtime. Getting it to install cleanly meant fixing packaging bugs, such as CORS and static-adapter issues, that only appear in a real install.

FastAPI, ChromaDB + BM25, SvelteKit, Tauri

EruVoice

Talk to a notes vault, and it can act

Speech goes through faster-whisper, then to Claude Code limited to a single vault MCP server, then back out through Piper or Kokoro TTS. The system prompt tells Claude the input is a transcription that may be wrong, so it asks before acting on an unclear command. Benchmarking showed int8 was about 10x slower than fp32 on the target CPU, so fp32 is the default.

Claude Code CLI, MCP, faster-whisper, Kokoro-82M

Erudition

Portable, git-backed memory for AI agents

An MCP server with 9 tools and Claude Code SessionStart and Stop hooks. Search uses a rebuildable SQLite FTS5 index over markdown files. To check the 82-test suite, I broke the path-traversal guard and the staleness check on purpose and confirmed the tests caught both.

View repository

Lyra

Typed pipeline stages an agent can call directly

Wraps retrieve, rerank, generate, and eval stages behind one interface and an MCP tool surface, so an agent calls run_stage instead of reading scripts. It works with both a CLI codebase (WiQAS) and a FastAPI service (Orion) with no changes to shared code.
